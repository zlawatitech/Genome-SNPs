# Comparative Genomics Analysis Pipeline

## Project Overview
Bioinformatics pipeline for identifying genomic variations (SNPs, structural variants, plasmid sequences) between control and treated samples from WGS data. Designed for reproducibility and clinical research applications.

## Key Analyses
- **SNP Detection**: Differential SNP calling and visualization
- **Structural Variants**: Chromosomal rearrangement analysis
- **Plasmid Identification**: BLAST-based plasmid sequence detection
